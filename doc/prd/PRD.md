## 1. 一句话定义

**以任务为单位、随时间主动推进的桌面 AI 助手。**

把所有渠道进来的活儿收进一个池子，替你盯住每件事现在处于什么状态，到点提醒，并在授权下直接动手推进。**电脑上干活，手机上（IM）看进度和拍板。**

区别于聊天式助手的关键一句：**对话只是入口，任务才是产品的主体。**

### 1.1 两条产品公理

**公理一：任务即上下文边界。**

| 规则 | 说明 |
|---|---|
| 一任务一线程 | 独立消息流、工具调用记录、产物、token 预算（子任务亦然；父线程只做汇总，不吞子任务全文） |
| 归属即迁移 | 消息一旦归属任务就移入该任务线程，不留全局 |
| **通道无关** | 桌面与 IM 写的是同一个 `thread_id`，通道只决定投递方式 |
| 跨任务不互灌 | AI 可检索其他任务的**摘要/事实**，但不注入全文 |
| 完成后归档 | 线程转只读；续做是"重开任务" |

不互灌的三条理由：**省 token**（命中前缀缓存）、**防串味**（客户/项目背景互相污染）、**防泄漏**（一个任务里的敏感材料不该出现在另一个任务）。

**公理二：AI 的一切动作都归属于某个任务。**

一次执行必然产出**产物**并挂在任务上，而不是散落在聊天记录里。无归属动作只允许发生在"快速问答"，且不落产物。

## 2. 背景与用户

### 2.1 三个困境

| 困境 | 表现 | 现有工具缺口 |
|---|---|---|
| **收不齐** | 会议交办、IM 一句话、邮件、临时想到 | 待办 App 全靠手打，用三天就弃 |
| **看不清** | 说不出"14 件事里 2 件等别人、4 件做了一半" | 看板要人维护，无人维护即失真 |
| **忘得掉** | 到点才想起；等别人的事没人追；半成品一周后彻底忘 | 提醒是闹钟，不懂上下文，不会追问 |

再加两件正在发生的事：**活儿越来越是交给 AI 干的**（现有产品一个大对话框装所有事，上下文互相污染）；**人不在电脑前**（会议中、通勤、客户现场，需要的是"能拍板"，不只是"收到提醒"）。

### 2.2 竞品为何不做

| 类型 | 代表 | 缺口 |
|---|---|---|
| 待办清单 | Todoist / 滴答清单 | 手打录入 + 手改状态，无上下文，不追问 |
| 团队协作 | 飞书任务 / Notion / Jira | 为协作与汇报设计，个人私事放不进去 |
| 通用助手 | ChatGPT / Claude | 对话结束即遗忘，**没有时间维度** |
| 办公 Copilot | M365 / 豆包 | 绑死单一套件，跨 IM / 邮件 / 本地文件收不进来 |
| 浏览器 Agent | browser-use 类 | 会操作网页，但不知道"你手上有哪些事" |

**空白点**：私有、跨来源、有时间感、一任务一工作区、手机上能按任务拍板、并且能动手的个人任务管家。

### 2.3 用户

| 画像 | 特征 | 核心诉求 |
|---|---|---|
| **A 多线执行者**（主力） | 同时跟 3–5 个项目，日均 8–15 件，来源以 IM + 会议为主 | 别漏、别乱、有人替我记 |
| **B 承上启下者** | 一半在等别人，一半被别人等 | 谁在等我、我在等谁 |
| **C 自由职业/外包** | 多客户并行，交付即收入 | 不延期、能出工作量证明 |

首版聚焦 **A**；B 的等待追踪是 P1 差异化；C 只做周报支持。

## 3. 范围

**做**：6 态任务管理、捕获（一句话/转发/剪贴板/语音）、看板与任务工作区、提醒与状态回访、每日复盘、IM 按任务维度的轻交互。

**不做**

- ❌ 团队协作 / 项目管理系统（指派、甘特图、审批流）
- ❌ 工时统计与计费
- ❌ 企业级权限（RBAC / SSO）
- ❌ 替代日历（只读日历感知占用）
- ❌ 全自动替你决策（写操作必须确认）
- ❌ **个人微信协议自动化**进产品（iLink 仅作自装插件，见 02-im §4.3）
- ❌ IM 里做重交互（长文、diff、配置修改）

## 4. 跨域契约（防重复实现的四条线）

| 契约 | 定义方 | 消费方 | 规则 |
|---|---|---|---|
| 状态与迁移矩阵 | 01-task §3 | 02-im、桌面 UI | 迁移合法性由 `task-core` 裁决，通道无权重写 |
| 提醒**语义**（何时/说什么/建议动作） | 01-task §5 | 02-im §9 | IM 只负责渲染与投递，不判断"该不该提醒" |
| 投递**能力**（载体/长度/回调/时延） | 02-im §3 §6 §9 | 01-task | 任务域不感知平台差异 |
| 动作白名单 | 02-im §7 | 01-task | 白名单内仍要过迁移矩阵 |
| 线程与事件流 | `03-session` | 双方 | 同一 `thread_id`，事件标 `channel` |
| 写操作审批 | `08-security` | 双方 | deny-until-approve，IM 侧必须点按钮 |

**一条铁律**：IM 适配器**不写库、不改状态**，只做"翻译 + 投递 + 回调"。

## 5. 全局指标

**北极星：周闭环任务数**（一周内创建且在本周内 `done` 的任务数）——同时衡量"收得进"和"做得完"。

| 层级 | 指标 | 目标（v1 三个月） |
|---|---|---|
| 激活 | 首日建 ≥ 3 条任务的用户占比 | ≥ 60% |
| 习惯 | 周留存（每周 ≥ 3 天有任务动作） | ≥ 40% |
| 价值 | 状态新鲜度（24h 内被推进或确认） | ≥ 80% |
| 价值 | 提醒响应率（1h 内有内联动作） | ≥ 45% |
| 价值 | 搁置处置率（30 天内继续/改期/取消） | ≥ 50% |
| 价值 | IM 参与闭环任务占比 | ≥ 20% |
| AI 价值 | 有 AI 参与的闭环任务占比 | ≥ 30% |
| AI 价值 | 状态建议采纳率 / IM 归属准确率 | ≥ 85% / ≥ 90% |
| **护栏** | 打扰投诉 | ≤ 1 次/周/人 |
| **护栏** | AI 越权改状态 | **0** |
| **护栏** | IM 白名单外动作 / 未绑定账号执行 | **0** |
| **护栏** | 跨任务上下文污染（人工抽检） | **0** |
| **护栏** | 状态手动改判率 | ≤ 15% |

## 6. 里程碑

| 阶段 | 范围 | 交付判据 | 周期 |
|---|---|---|---|
| **M0** | 本套 PRD 定稿 + 决策拍板（§8） | 无阻塞项 | 3 天 |
| **M1 可用闭环** | 6 态状态机与看板 + 捕获 + 状态建议 + 任务工作区 + 提醒与回访 + 复盘 + IM（飞书/钉钉双工；微信 L1+L2） | 连续用 2 周不弃；提醒零漏发；IM 一句话落到对的任务；`paused` 按节奏回来 | 7–8 周 |
| **M2 AI 捕获与排期** | 自动抽任务收件箱 + 智能排期 + 上下文自动挂载 | 抽取准确率 ≥ 70%，误抽可一键忽略 | 6 周 |
| **M3 主动推进** | 等待追踪 + 追问进展 + 周报 + 搁置清点 + 委托执行（审批） | 等待任务平均解除时长 −30%；搁置处置率 ≥ 50% | 6 周 |

**M1 的取舍**：只做"记得住 + 状态准 + 提醒对 + 一件事一个工作区 + 手机上能拍板"，**不做**自动抽取。6 态与 IM 归属是两大复杂度来源，先做扎实。

## 7. 跨域风险

| 风险 | 影响 | 对策 |
|---|---|---|
| **6 态手选成本** | 用户懒得选，状态失真 | AI 建议一键确认 + 快捷键/拖拽 + 自动迁移；IM 一句话即切 |
| **`blocked`/`paused` 分不清** | 两列都堆东西 | 01-task §4 一句话判据 + 用词表；不确定默认 `blocked` |
| **IM 消息落错任务** | 改错状态、串味 | 推送即锚定 + 五层短路 + 候选点选；不猜；归属留痕 |
| **IM 成远程控制台缺口** | 账号被盗即被操控 | 绑定 + 白名单 + 审批必须点按钮 + 日预算 |
| **第三方网关让数据出本机** | 隐私底线失守 | 默认不装；自装插件显式确认；主链路不依赖 |
| **录入成本高于收益** | 用三天弃用 | 零必填、转发即录入、字段残缺也可用 |
| **提醒疲劳** | 关通知 = 产品死亡 | 上限 + 合并 + 降频；`paused` 只进复盘 |
| **搁置变黑洞 / 变垃圾桶** | 半成品不复活，或什么都"先放着" | 强制 `progress_note` + 退避回访；3 轮后直问"要不要取消" |
| **跨任务上下文串味** | 隐私事故 | 线程物理隔离；跨任务只注入摘要；抽检 0 事故 |
| **跨平台适配失控** | 工期爆炸 | M1 只做飞书/钉钉双工 + 微信 L1/L2 |

## 附：与"通用 Agent"的差异

| | 通用 Agent | 本产品 |
|---|---|---|
| 交互单位 | 会话 | **任务**（一任务一线程一工作区） |
| 记忆 | 会话内 + 向量回忆 | 任务状态机（6 态）+ 时间线 + 跨任务事实摘要 |
| 主动性 | 提问才动 | **时间与上下文双触发**（到期、逾期、`blocked` 升级、`paused` 回访） |
| 手机端 | 一个大对话框 | **按任务锚定**：点按钮 / 回一句即落到那条任务 |
| 产物 | 一段回答 | 挂在任务上的产物 + 一个状态变化 |
| 多线程 | 单窗口，上下文互相污染 | 按任务物理隔离，切任务不串味 |
| 半成品 | 新开对话从零开始 | **`paused` 可接续**：进度一行 + 产物冻结 + 线程还在 |
