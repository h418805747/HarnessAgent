# M1 实施计划 · 可用闭环

> 对应 PRD：`doc/prd/PRD.md`（总纲）、`01-task.md`（任务域）、`02-im.md`（IM 通道）
> 周期：7–8 周（单人全职估算）
> 目标：**自己连续用 2 周不弃**

---

## 1. 完成定义（DoD）

| # | 判据 | 验证方式 |
|---|---|---|
| 1 | 连续自用 14 天，日均建 ≥ 3 条任务 | 使用日志（本地） |
| 2 | 提醒零漏发 | 构造 50 条用例（含重启、静默期、离线补偿）全部按时或按合并规则投递 |
| 3 | IM 指令归属准确率 ≥ 90% | 30 条真实口语句子跑离线集 |
| 4 | 切任务上下文完全隔离 | 人工抽检 20 次，跨任务关键词命中 = 0 |
| 5 | 白名单外动作 / 未绑定账号执行 = 0 | 注入攻击用例（含"同意/可以/发吧"文本冒充审批） |
| 6 | `paused` 按 3/7/14/30 天回访，且不单独弹窗 | 时间旅行测试（可注入假时钟） |
| 7 | 6 态迁移非法组合全部被拒 | 36 组迁移矩阵表驱动测试 |

## 3. 工作分解（6 条工作流）

### W1 · 领域层 `task-core`（1.5 周）

**产出**
- SQLite schema（§4）与迁移脚本
- `ITaskService`：`create / transition / query / brief / todayBrief`
- **状态机守卫**：36 组矩阵表驱动；`blocked` 需 `waiting_on`、`paused` 需 `pause_reason`；`paused` 带进展需 `progress_note`
- 事件：`task.created` / `task.status_changed` / `task.updated` / `task.deleted`
- 父子规则：单层校验、拆解规模 2–7 校验、父完成三选一

**验收**：矩阵非法组合全拒且给出可读错误码；`transition()` 是唯一写入口（UI/IM 都调它）。

### W2 · 捕获与状态建议（1 周）

- 全局热键 `⌥Space` 捕获框（冷启动 ≤ 300ms，回车即存，零必填）
- 剪贴板捕获、IM 转发入口（先通一条链路即可）
- `status-infer` 技能：原话 → 建议状态 + 置信度 + 建议字段（`waiting_on` / `pause_reason` / `defer_until`），依据 `01-task.md` §4 用词表
- 降级：解析失败 → 纯标题 `todo`，不弹表单

**验收**：20 句真实输入，建议命中 ≥ 15；失败不阻塞创建。

### W3 · 提醒与调度（1 周）

- `ITaskReminder.plan(task)` 生成 `slot` 计划（语义层，不含通道）
- `blocked` 递增曲线（2/3/5/7）、`paused` 递减曲线（3/7/14/30，只进复盘）
- 幂等表 `reminder(task_id, slot)` 唯一索引
- 静默合并、单日上限、连续忽略降频、启动补偿扫描
- 可注入时钟（测试用）+ `reminder.fired` 埋点

**验收**：50 条用例零漏发、零重发；时间旅行可复现全部曲线。

### W4 · 任务工作区 UI（1.5 周）

- 看板六列：待办 / 进行中 / 等待中 / 搁置中（折叠）/ 已完成（折叠）/ 已取消（折叠）
- 卡片：标题、短码、相对时间、优先级、状态徽标（`blocked` 带"等 X · N 天"，`paused` 带"搁 N 天"）、run 指示
- 任务工作区三栏：状态条（六态一键切 + AI 建议）/ 线程（复用 `03-session`）/ 执行面板（run 状态、产物、审批、轨迹）
- **父子视图**：父页进度 `n/m` + 子任务列表；点子任务进独立工作区；面包屑返回
- 子任务上下文继承（父目标 + 共享文件 + 兄弟一行列表）与摘要回写

**验收**：切任务 ≤ 300ms 且上下文隔离；父→子 1 次点击；复活 `paused` 首屏有"上次停在…"。

### W5 · IM 通道骨架 + 飞书/钉钉（1.5 周）

- `IImAdapter` 接口 + `capabilities()`（buttons/dropdown/numbered/h5）
- 飞书适配器：卡片 + 按钮 + 回调；钉钉：ActionCard
- **推送即锚定**：出站消息登记 `msg_id → task_id`
- 五层归属：L0 点选 / L1 引用 / L2 短码 / L3 粘性 / L4 语义（阈值 0.8）
- 不确定 → 候选点选（≤ 3 个 + "更多"）
- `im.routed` 埋点（layer + confidence），用于算准确率

**验收**：30 句离线集准确率 ≥ 90%；候选点选路径可用；重复回调不重复执行。

### W6 · 微信 L1/L2 + 安全（1 周）

- **L1**：桌面通知 + 系统镜像说明页（Phone Link / 小米妙享 / 华为多屏协同 引导）
- **L2**：剪贴板/拖拽捕获 → 走五层归属（L2 短码为主）
- 载体降级：C 编号回执（"1 完成 / 2 搁置 / 3 改期"）+ D H5 落地页（一次性 token）
- 安全：账号绑定码、白名单、审批只认按钮、`platform+msg_id` 去重、会话日预算、`channel=im` 留痕

**验收**：注入"同意/可以/发吧"文本不触发任何写操作；未绑定账号零响应。

### W7 · 复盘（0.5 周）

- 日终 18:30：完成 N / 等待 M / 搁置 K（最长 N 天）/ 明日 Top3
- 一键生成日报文本；未完成项批量顺延
- 周复盘：搁置 > 30 天清单 + 按项目聚合

### W8 · 联调与打磨（1 周）

- 端到端：捕获 → 建议 → 提醒 → IM 拍板 → 归档
- 指标埋点核对（§6）
- 崩溃恢复：进程重启后提醒补偿、幂等表校验
- 开始 14 天自用观察

## 4. 数据表草案（SQLite）

```sql
CREATE TABLE task (
  id            TEXT PRIMARY KEY,
  short_code    TEXT UNIQUE NOT NULL,          -- T-7F3
  title         TEXT NOT NULL,
  raw_input     TEXT NOT NULL,
  status        TEXT NOT NULL,                 -- todo|doing|blocked|paused|done|canceled
  due_at        INTEGER,                       -- epoch ms，null = 无期限
  due_precision TEXT,                          -- day|minute
  priority      INTEGER NOT NULL DEFAULT 2,
  estimate      INTEGER,
  source        TEXT NOT NULL,
  project       TEXT,
  parent_id     TEXT REFERENCES task(id),
  defer_until   INTEGER,
  waiting_on    TEXT,
  waiting_since INTEGER,
  paused_at     INTEGER,
  pause_reason  TEXT,
  progress_note TEXT,
  resume_when   TEXT,
  pause_rounds  INTEGER NOT NULL DEFAULT 0,
  resume_check_at INTEGER,
  thread_id     TEXT NOT NULL,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,
  done_at       INTEGER
);

CREATE INDEX idx_task_status_due ON task(status, due_at);
CREATE INDEX idx_task_project    ON task(project);
CREATE INDEX idx_task_parent     ON task(parent_id);
CREATE UNIQUE INDEX idx_task_single_level ON task(parent_id) WHERE parent_id IS NOT NULL;

CREATE TABLE reminder (
  task_id  TEXT NOT NULL,
  slot     TEXT NOT NULL,
  state    TEXT NOT NULL,          -- pending|fired|acked|snoozed|canceled
  fire_at  INTEGER NOT NULL,
  channel  TEXT,
  msg_ref  TEXT,
  fired_at INTEGER,
  PRIMARY KEY (task_id, slot)      -- 幂等
);

CREATE TABLE im_msg_map (
  platform TEXT NOT NULL,
  msg_id   TEXT NOT NULL,
  task_id  TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  PRIMARY KEY (platform, msg_id)   -- 引用锚定
);

CREATE TABLE im_seen (
  platform TEXT NOT NULL,
  msg_id   TEXT NOT NULL,
  PRIMARY KEY (platform, msg_id)   -- 入站去重
);
```

**说明**：单层父任务用 `CHECK` 语义在应用层实现（SQLite 的 `WHERE` 部分索引不校验层级，需在 `transition`/`create` 时查父的 `parent_id` 是否为空）。

## 5. 接口与事件清单

```text
# 领域
ITaskService.transition(taskId, to, {actor, channel, reason, patch}) -> Task | Err
ITaskService.todayBrief() -> {due, overdue, blocked, paused, top3}
ITaskService.children(taskId) -> Task[]

# 提醒（语义层）
ITaskReminder.plan(task) -> Reminder[]
ITaskReminder.ack(taskId, slot, action)

# IM（适配器只翻译，不写库）
IImAdapter.capabilities() -> {buttons, dropdown, numbered, h5, maxLen, callback}
IImAdapter.send(OutboundMessage)
IImAdapter.onCallback(payload) -> InboundIntent
```

事件（全部带 `thread_id` 与 `channel`）：

| 事件 | 用途 |
|---|---|
| `task.created` | 建任务、来源统计 |
| `task.status_changed` | 审计、回放、状态新鲜度 |
| `task.run.finished` | 摘要回写父线程、复盘 |
| `reminder.fired` | 触达率 |
| `reminder.acked` | 响应率 |
| `im.routed` | 归属准确率（layer + confidence） |
| `im.action_rejected` | 护栏（必须为 0） |

## 6. 埋点与看板（自用也要看）

最小集：任务创建数/日、状态变更次数、提醒触发/响应、IM 归属层次分布、`paused` 存活曲线、父任务拆解数量分布。

用途：14 天自用时能回答"哪一步最烦"——这决定 M2 优先级。

## 7. 风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 6 态守卫遗漏 | 出现非法迁移 | 矩阵表驱动测试，36 组全覆盖；`transition` 单一入口 |
| 子任务上下文膨胀 | 子任务首轮 token 明显偏高 | 继承只给父目标 + 兄弟一行列表；超预算即裁剪 |
| 提醒漏发 | 用例失败 | 幂等表 + 启动补偿 + 假时钟回归 |
| IM 回调签名/重放 | 重复执行 | `im_seen` 去重 + 回调验签 |
| 微信 L1 镜像不可用 | 手机收不到 | 桌面通知保底；首次运行做镜像可用性自检并提示 |
| 范围蔓延 | 想加自动抽取 | M1 明确不做；新想法记进 M2 待办 |
